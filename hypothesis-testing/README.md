# 📊 Hypothesis Testing

Welcome to my **Statistical Hypothesis Testing** portfolio! 🧪📈

This repository contains **three data analytics projects** completed as part of the **Google Advanced Data Analytics Certificate**.

The projects demonstrate how statistical methods can be used to explore data, test hypotheses, identify statistically significant differences, and generate **data-driven business insights**.

---

## 📁 Projects

### 🚕 1. Automatidata — Taxi Data Analysis

**Business Scenario:** New York City Taxi & Limousine Commission (TLC)

This project focuses on analyzing taxi trip data and applying **statistical hypothesis testing** to investigate differences in the dataset and support business decision-making.

🔍 **Key Areas:**

* 🧹 Data cleaning & preparation
* 📊 Exploratory Data Analysis (EDA)
* 💡 Hypothesis formulation
* ⚖️ Null & alternative hypotheses
* 🧪 Statistical hypothesis testing
* 📉 P-values & statistical significance
* 🔎 Interpretation of statistical results
* 💼 Business insights & communication

📓 **Notebook:** `Automatidata_Hypothesis_Testing.ipynb`

---

### 🎵 2. TikTok — Claims Classification Analysis

**Business Scenario:** TikTok

This project analyzes TikTok user-report data as part of a project focused on identifying whether videos contain **claims or opinions**.

Statistical analysis and hypothesis testing are used to investigate differences between groups in the dataset.

🔍 **Key Areas:**

* 🧹 Data exploration & preparation
* 📊 Exploratory Data Analysis
* 👥 Group comparisons
* 💡 Hypothesis formulation
* 🧪 Statistical testing
* 📉 P-values & statistical significance
* 🔎 Interpretation of results
* 💼 Data-driven business insights

📓 **Notebook:** `TikTok_Hypothesis_Testing.ipynb`

---

### 🗺️ 3. Waze — User Churn Analysis

**Business Scenario:** Waze

This project focuses on analyzing Waze user data to investigate **monthly user churn**.

A **two-sample hypothesis test** is used to investigate differences between groups of users and provide insights that can support data-driven decisions.

🔍 **Key Areas:**

* 🧹 Data cleaning & preparation
* 📊 Exploratory Data Analysis
* 👤 User behavior analysis
* 🔄 Churn analysis
* 🧪 Two-sample hypothesis testing
* ⚖️ Null & alternative hypotheses
* 📉 Statistical significance
* 🔎 Interpretation of results
* 💼 Business insights

📓 **Notebook:** `Waze_Hypothesis_Testing.ipynb`

| 📚 Concept                     | 🔍 Description                                         |
| ------------------------------ | ------------------------------------------------------ |
| 📊 Descriptive Statistics      | Summarizing and understanding data                     |
